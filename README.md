# Founder Tip Tuesday: week of October 20, 2026

Peter Walker of Carta benchmarked more than 1,000 software rounds from the prior six months. His point: valuation is often the output of cash raised and dilution, so start a raise from how much cash you really need, priced against the next proof point.
